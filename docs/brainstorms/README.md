# Brainstorms

Brainstorms are temporary working documents for shaping a possible change before it becomes a plan,
ADR, or live TODO item.

Once the decision is made or the work is implemented, fold durable requirements into `docs/plans/TODO.md`,
`CONTEXT.md`, or an ADR, then delete the brainstorm. Do not keep completed brainstorms here as an archive;
git history is the provenance record.
