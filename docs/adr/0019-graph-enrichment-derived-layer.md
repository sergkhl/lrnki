# Give Graph Enrichment exclusive ownership of inferred graph facts

Status: Accepted (reset 2026-06-15 — exhaustive same-domain CEP-pair judgment; generalized 2026-06-16 — node + edge derivation; amended 2026-06-18 — densification removed and intrinsic difficulty adopted; amended 2026-06-19 — prerequisite hint label removed; amended 2026-06-22 — per-node batched judging; coverage unchanged, call grouping regrouped; amended 2026-06-23 — derived-layer semantic deduplication sub-stage; amended 2026-06-23 — minting-durability judge; amended 2026-06-24 — whole-set ordering replaces per-pair / per-node-batched judging; promotion gated on study value)

## Decision

Graph Enrichment is the only operation that creates learner-neutral graph facts not asserted by a source. Each execution is an immutable **Enrichment Run** over one explicit published graph version and one enrichment configuration. It produces one **Derived Graph Layer** stored separately from the asserted graph.

Graph Enrichment derives **nodes as well as edges**. Beyond the published anchors it may **rescue** `source_mentioned` nodes (concepts a member Extraction Run mentioned verbatim but never defined, drawn from that run's rejected/optional admission proposals) and **mint** `llm_grounded` nodes for prerequisite concepts the source assumes but never teaches. Minted nodes carry `mintingReason: "assumed_prerequisite"` (the prior experiment-only `densification` reason was removed with F3 — see "no densification pass" below). Anchor-driven assumed-prerequisite minting remains bounded per-anchor and per-run. Minting is two stages — an inspectable proposal of node identity, then grounding generation — never local string construction. Every minted node carries a CEP-shaped generated grounding bundle, swappable in place by a later retrieval upgrade without changing node identity. No rescued or minted node ever enters the asserted graph; the asserted layer stays anchors-only with a verbatim evidence floor and zero asserted edges. The grounding-origin model and the non-verbatim trust contract for generated grounding live in ADR-0023.

**Rescue is durability-judged before a node is created (2026-06-16 refinement, U3).** After mention dedupe/merge, each aggregated rescue candidate passes a measured, cross-family **rescue durability judge** (`kg-independent-judge`) conditioned on the same-domain anchors it would scaffold: is it a durable prerequisite a learner must grasp before those anchors, or an incidental artifact (a method/system/ablation label, a pedagogical-role label, a source-local detail)? The judge is **drop-only** and **fails open with a flag** (KTD3, AGENTS rule 16): it removes a candidate only on a confident verdict whose grounding span is verbatim-present in the candidate's own mention evidence; on transport failure, invalid tool args, or an ungrounded verdict the node is **kept and flagged** `kept_judge_unavailable`, never silently vetoed. A dropped candidate's label stays reserved so minting cannot resurrect it. Every candidate's `accepted` / `dropped` / `kept_judge_unavailable` disposition is recorded on the Enrichment Run trace and persisted relationally. This is a measured neural gate, not a lexical deny-list of role or method names.

**Minting is durability-judged before generated grounding is created (2026-06-23 amendment).** Each reserved assumed-prerequisite proposal may pass through an opt-in cross-family **minting durability judge** (`kg-independent-judge`) before it becomes an `llm_grounded` node. The judge asks whether the proposed concept is a durable prerequisite the anchor's material genuinely depends on, or whether it is merely named in passing, tangential, or adjacent. It is **drop-only**: `not_durable` records a dropped minting disposition and no grounding-generation call is spent; `durable` records an accepted disposition and the normal grounding step proceeds; transport or schema failure fails open as `kept_judge_unavailable`. A dropped proposal's normalized label remains reserved in its Declared Domain so a later anchor cannot resurrect it. Because minted proposals have no source mention quotes, this gate cannot reuse the rescue judge's verbatim grounding-span safety; instead it follows ADR-0023's cross-family principle for generated-node work and stays inspectable through persisted `minting_dispositions`. Omitting the judge port keeps the prior minting behavior and emits no minting dispositions; enabling it changes derivation and therefore the enrichment configuration hash.

**The derived node set is semantically deduplicated before ordering (2026-06-23 amendment, plan U1–U5).** After the derived node set is assembled (anchors ∪ rescued ∪ minted) and before whole-set prerequisite ordering, an opt-in **semantic-deduplication sub-stage** collapses same-domain near-duplicate nodes, so duplicate nodes never reach the ordering call and prerequisite chains form on the collapsed set. It strictly separates **propose** from **decide** (ADR-0012, AGENTS rule 20): embeddings (`kg-node-embedding`) propose within-domain near-duplicate candidate pairs by cosine with a recall-generous threshold and a bounded top-N per node — they never merge — and a separate **cross-family merge adjudicator** (`kg-independent-judge`) decides each proposed pair as `merge` or `keep_distinct`. Raw cosine never decides; a very-high-similarity pair is still routed to the adjudicator. Merged pairs are unioned (a transitive cluster collapses to one canonical); canonical selection is deterministic and recorded — an **anchor always wins** over an enrichment node, then more evidence, then lower stable id — so a merge only ever removes a derived enrichment node and **never mutates published Concept identity, IRIs, or the asserted version** (the published-identity boundary stays deterministic per ADR-0015; KTD1). A two-anchor cluster is refused outright. A merge keeps the canonical node, adds the absorbed surface labels as derived-layer aliases, threads the absorbed evidence into the canonical node's judge context, and records full propose+decide+canonical-selection provenance to `derived_node_merges` for Admin Lab inspection. The pass **fails closed**: an embedding failure skips that domain and an adjudicator failure degrades that pair to `keep_distinct`, both surfaced, never a silent merge (R13). It is opt-in — omitting either port leaves enrichment behavior identical (the exact-label baseline) — and changing it re-derives the layer via the enrichment config hash. The dedup decision is inherently judgment-based and is evaluated by real-use inspection, never a deterministic proxy (AGENTS rules 11/19); embeddings here only propose identity candidates and are never used to derive a prerequisite (ADR-0012).

Enrichment derives prerequisite edges with **one whole-set ordering call per Declared Domain over the deduplicated union of anchors and enrichment nodes (amended 2026-06-24, plan U1–U7)**, feeding the ordering judge each node's evidence — an anchor's published Concept Evidence Profile, a rescued node's verbatim mention passages, or a minted node's generated grounding. Source-stated prerequisite prose reaches the judge as ordinary mention evidence; the former labeled prerequisite-hint assertion was measured redundant and removed (ADR-0016). **This replaces the prior per-pair / per-node-batched judging (rule 18).** Pairwise judgment is intransitive by nature — a judge can call A→B, B→C, and C→A all locally plausible — so cycles were the *expected* residue, mopped up after the fact; no per-pair call ever saw the whole set. A whole-set call returns a directed edge list that is **globally self-consistent by construction**, has no privileged subject (so the per-pair subject/candidate direction asymmetry cannot arise), and converts the question "is the whole thing acyclic?" into a **provable structural** one that belongs in the deterministic envelope. The single ordering alias is **cross-family** from the DeepSeek extractor + grounding generator (ADR-0023), so the generator never grades its own minted output and the per-pair anchor/generated routing split is gone. The application owns every provable guarantee (rules 16/19): each edge cites its two endpoints by exact canonical label and is mapped → `derivedNodeId` **fail-closed** (an endpoint outside the judged set, or one concept named as its own prerequisite, fails the run, never a guessed node); acyclicity is **verified**, and on a cycle the boundary issues **at most one** corrective re-prompt naming the violating cycle, then routes any still-cyclic edges **wholesale to `uncertain`** (kept, flagged, path-excluded — never dropped by lowest-confidence removal). A no-evidence node is excluded from the ordering input and recorded once. One ordering call per domain; a domain whose assembled prompt exceeds a configured token budget fails the run closed without a partial layer (no chunking, no DAG merging). If the ordering call exhausts the forced-tool retry budget the run fails without persisting a partial layer. An Enrichment Run records its model identity, one per-domain ordering trace (asserted edges, whether the re-prompt fired, cycle-routed edges), per-node insufficient-evidence exclusions, the per-node verbatim-floor dispositions, and deterministic edge dispositions (weak-edge cutting, transitive reduction). The relational Derived Graph Layer is the query surface; one immutable JSONB artifact (`enrichment_run.v3`) retains the complete trace. Repeated executions with the same version and configuration remain distinct runs.

Graph Enrichment also scores every derived node with learner-neutral intrinsic difficulty. The difficulty method, its fused components, and its `EXPERIMENT_ONLY` trust are owned by ADR-0024; here the only enrichment-scope commitments are that every derived node is scored and that prerequisite edges remain the primary learner-path constraint while difficulty is a secondary signal.

Graph Enrichment never mutates the asserted graph and never reuses an asserted relation name; its only predicate is `inferred-prerequisite-of` (ADR-0016) — ordering is always an edge, never a node attribute. There is no densification/bridge-proposal pass: the removed F3 experiment is summarized as a completed outcome in `docs/plans/TODO.md`, not here.

**Promotion is gated on absolute study value, not parity (2026-06-24 amendment, plan KTD1).** Whole-set ordering ships single-sample. Because both the whole-set and the deleted per-pair edge sets are plausible DAGs over genuinely ambiguous concepts — neither is ground truth — matching the prior baseline is neither necessary nor sufficient. Promotion out of `EXPERIMENT_ONLY` is gated on whether the whole-set DAG produces *sensible study paths* against a rubric derived from concrete observed defects: general foundations sit at/near DAG roots (not gated behind domain-specific anchors); leaf-target prerequisite closures stay shallow (no near-total order); central "headline" concepts are reachable by a short path; an already-good chain survives unharmed; and every cycle→`uncertain` routing is inspectable in Admin Lab. Net cost staying at or below the prior baseline is a secondary check, not the gate, evaluated by real-use inspection and LLM-as-judge, never a deterministic proxy (rules 13/14/19). Single-sample is explicitly first, not final: K-sampling for direction-instability on ambiguous pairs is gated follow-up (`docs/plans/TODO.md`).

## Context

Inferred prerequisite structure requires graph-global judgment and does not belong in a per-source Extraction Run or the deterministic asserted Graph-Version Build. With the core kept intentionally small, a single whole-set ordering call per domain is the simplest behavior that makes prerequisite structure *globally* coherent: it gives the model the whole node set at once (which per-pair and per-node-batched judging never did), makes acyclicity a provable structural check rather than a post-hoc lowest-confidence repair, and removes both the per-pair routing split and the embedding-clustering blocking tier, whose hard-gating role was never earned. Separate Enrichment Runs keep publication provenance-pure while making inferred structure inspectable and independently replaceable by later methods.
