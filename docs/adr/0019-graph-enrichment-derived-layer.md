# Give Graph Enrichment exclusive ownership of inferred graph facts

Status: Accepted (reset 2026-06-15 — exhaustive same-domain CEP-pair judgment; generalized 2026-06-16 — node + edge derivation; amended 2026-06-18 — densification removed and intrinsic difficulty adopted)

## Decision

Graph Enrichment is the only operation that creates learner-neutral graph facts not asserted by a source. Each execution is an immutable **Enrichment Run** over one explicit published graph version and one enrichment configuration. It produces one **Derived Graph Layer** stored separately from the asserted graph.

Graph Enrichment derives **nodes as well as edges**. Beyond the published anchors it may **rescue** `source_mentioned` nodes (concepts a member Extraction Run mentioned verbatim but never defined, drawn from that run's rejected/optional admission proposals) and **mint** `llm_grounded` nodes for prerequisite concepts the source assumes but never teaches. Minted nodes carry `mintingReason: "assumed_prerequisite"`; the prior experiment-only `densification` minting reason was removed after F3 produced no measured value on the connected baseline. Anchor-driven assumed-prerequisite minting remains bounded per-anchor and per-run. Minting is two stages — an inspectable proposal of node identity, then grounding generation — never local string construction. Every minted node carries a CEP-shaped generated grounding bundle, swappable in place by a later retrieval upgrade without changing node identity. No rescued or minted node ever enters the asserted graph; the asserted layer stays anchors-only with a verbatim evidence floor and zero asserted edges. The grounding-origin model and the non-verbatim trust contract for generated grounding live in ADR-0023.

**Rescue is durability-judged before a node is created (2026-06-16 refinement, U3).** After mention dedupe/merge, each aggregated rescue candidate passes a measured, cross-family **rescue durability judge** (`kg-independent-judge`) conditioned on the same-domain anchors it would scaffold: is it a durable prerequisite a learner must grasp before those anchors, or an incidental artifact (a method/system/ablation label, a pedagogical-role label, a source-local detail)? The judge is **drop-only** and **fails open with a flag** (KTD3, AGENTS rule 16): it removes a candidate only on a confident verdict whose grounding span is verbatim-present in the candidate's own mention evidence; on transport failure, invalid tool args, or an ungrounded verdict the node is **kept and flagged** `kept_judge_unavailable`, never silently vetoed. A dropped candidate's label stays reserved so minting cannot resurrect it. Every candidate's `accepted` / `dropped` / `kept_judge_unavailable` disposition is recorded on the Enrichment Run trace and persisted relationally. This is a measured neural gate, not a lexical deny-list of role or method names.

Enrichment judges **every unordered same-domain pair exhaustively over the union of anchors and enrichment nodes**, feeding the prerequisite judge each node's evidence — an anchor's published Concept Evidence Profile, a rescued node's verbatim mention passages, or a minted node's generated grounding. An `explicit-prerequisite-hint` is labeled evidence the judge may weigh, never a deterministic edge, numeric prior, or direction override. Any pair touching a generated node is ordered by a cross-family judge (ADR-0023); anchor-only pairs stay on the validated judge. Pair calls use configurable bounded concurrency (default four) and preserve deterministic pair/result order; if any pair exhausts the forced-tool retry budget the run fails without persisting a partial layer. An Enrichment Run records its model identities, pair judgments, the per-node verbatim-floor dispositions, and deterministic edge dispositions (weak-edge cutting, cycle removal, transitive reduction). The relational Derived Graph Layer is the query surface; one immutable JSONB artifact retains the complete trace. Repeated executions with the same version and configuration remain distinct runs.

Graph Enrichment also scores every derived node with learner-neutral intrinsic difficulty (ADR-0024). The difficulty producer fuses a forced-tool neural subscore with deterministic graph/evidence components and returns the existing `ConceptDifficulty` shape. Prerequisite edges remain the primary learner-path constraint; difficulty is a secondary tie-break and remains `EXPERIMENT_ONLY` trust until learner data exists.

Graph Enrichment never mutates the asserted graph and never reuses an asserted relation name; its only predicate is `inferred-prerequisite-of` (ADR-0016) — ordering is always an edge, never a node attribute. There is no densification/bridge-proposal pass. F3 v1 found zero bridges because the same-domain baseline was already connected; F3 v2 stopped before live proposal because no domain-neutral threshold/input source surfaced the documented economics region without fixture-specific calibration. Any future cost-bound pair-selection mechanism is separate follow-up work and must be measured against exhaustive judgment before it can veto pairs.

## Context

Inferred prerequisite structure requires graph-global judgment and does not belong in a per-source Extraction Run or the deterministic asserted Graph-Version Build. With the core kept intentionally small, exhaustive same-domain pair judgment is the simplest correct behavior and removes the embedding-clustering blocking tier, whose hard-gating role was never earned. Separate Enrichment Runs keep publication provenance-pure while making inferred structure inspectable and independently replaceable by later methods.
