# Persist only authored Support visibility in Learner State

Status: Accepted

Support is authored through [exact Activity references](../../content/AUTHORING.md#exact-reference-support-paths).
Learner State stores only whether each named path is open or hidden, keeping repairs small without
persisting generated branches or copied content.

Through [ordinary acquisition identity](0026-typed-study-item-bank.md), Support may repair the
referenced Stop's evidence. The branch itself cannot award parent progress or duplicate score.
